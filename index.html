Proof-Carrying Models

A model artifact that can prove its own history: what it was trained on, in what order, and which evaluation claims about it are evidence rather than theatre. The deciding property: the tier is derived, never declared — an artifact claiming "proven" gets what it earned, and nothing written on the artifact can say otherwise.

Model cards and leaderboards are assertions — the reader trusts the publisher. Regulation is about to demand what only a mechanism can honestly supply. This mechanism makes the claims checkable arithmetic: anyone holding the artifact and its chain re-derives the tier. The document of record is the README of this repository; this page carries the mutation-gated reference law, runnable below.

1 · Step identity — the closed set

A training step is exactly { parent, data, note? }, hashed over a canonical serialization so identity depends on content, never key order. Any other field refuses by name: what the hash does not cover, the chain cannot vouch for — an unhashed field is a smuggling channel that would let two different artifacts share an identity. The hash is frozen and pinned by test: changing it would orphan every existing lineage, so the suite makes that loud.

2 · The lineage — begins at null, or it hides something

step 0: parent must be null — "fine-tuned from something we won't name" is the hole this closes step n: parent === id(step n−1) — the first break is named by index any tamper, anywhere — changes that id and severs everything after it

3 · The verdict — the anti-theatre rule

An eval claim counts only if it names the chain head it actually evaluated and carries a reproducible digest and scores in [0,1]. A claim failing any test is ignored and listed with its reason — not an error, just nothing. Then: valid chain → lineaged · 1–2 counting evals → evaluated · ≥3 counting with mean ≥ κ (0.618) → proven. Three weak evals stay evaluated: quantity is not quality.

Run the reference law — attest an artifact

A 3-step lineage and four eval claims: one honest, one with no digest, one that evaluated a different artifact, one with an impossible score. Then tamper with the middle training step and watch every step after it sever.

What already runs · what must catch up

Gated and live today: the reference law in this page (35/36 killed + 1 argued equivalent, the argument in the baseline) · proven-web (signed, expiring verdicts) · fallineage (Ed25519 chains) · kcc-mint (provenance at 1,410-repo scale) — and the estate runs derived-not-declared tiers in production over 90+ repos.

The honest speculation: training loops emitting signed steps natively · an ecosystem convention for what an eval digest digests. Not claimed: that a digest is honest — only that a claim without one is nothing; the gate moves dishonesty from cheap assertion to forgeable artifact, where cryptography already applies.
